🧠 Rule Engine Defaults

Set page-level defaults for all rows. Per-row CSV columns override these. Rules merge with the filters above — conflicts are flagged in red.

Rule descriptions ▸
Rule Effect
ENV=Production Excludes B-series (burstable), enforces current-gen, min 4 vCPU for web/DB
OS=Windows De-prioritises ARM (Dpds/Dplsv5) families; prefers Intel or AMD
Workload=Web Server D/F families first; Database → E/M families first; ML/AI → NC/ND families first
Compliance=HIPAA/PCI Excludes B-series; enforces current-gen
Min Gen=v5+ Excludes v3/v4 series; keeps Dsv5, Esv5 and newer only
Workload=SQL Server Enforces a 4-vCPU licence floor when it can — SQL Server is licensed per core (minimum four), so a smaller box saves no licence cost. If no eligible candidate is that large, the fallback pick is kept and the rule is reported as not applied.
Workload=ML/AI (GPU) Requires a GPU/accelerator instance; every other workload excludes accelerators, so a GPU box is not recommended by accident. If the pool has no accelerator to offer, the fallback pick is kept and the rule is reported as not applied.
